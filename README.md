# Norah Almishdaq — Portfolio

Personal portfolio of **Norah Almishdaq**, AI Engineer (Generative AI & AI Agents) based in Riyadh, Saudi Arabia.

Built with plain HTML5, CSS3 and vanilla JavaScript, with no build step and no dependencies.

| File         | Purpose                                                              |
| ------------ | -------------------------------------------------------------------- |
| `index.html` | Page structure and content                                           |
| `style.css`  | Dark theme, layout, responsive breakpoints, animations               |
| `script.js`  | Mobile menu, smooth scrolling, scroll reveal, project cards, hero canvas |

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```
